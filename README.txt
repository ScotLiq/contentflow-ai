ContentFlow AI - Clean Desktop Prototype

Run using CMD:
1. Extract this ZIP.
2. Open CMD inside the extracted folder.
3. Run:

   start index.html

Folder structure:
contentflow-ai-desktop-clean
├── index.html
├── css
│   └── styles.css
├── js
│   └── app.js
└── assets
    ├── logo.svg
    ├── robot.svg
    ├── avatar.jpg
    ├── coffee.jpg
    ├── iced-coffee.jpg
    ├── beans.jpg
    └── cafe.jpg

Main flow:
Input setup → AI Generated Ideas → Human Caption Review → Schedule → Final Plan → Post/Export → Feedback Loop → Analytics.

Notes:
- No workflow map page is included.
- Feedback becomes available only after clicking Post / Export Content on the Final Plan page.
- The layout is desktop-first with a max-width content area so it does not stretch too wide.
